# 人工抽检复核模板

LLM-as-Judge 只是辅助评分，本项目建议抽检 20% 样本进行人工复核。人工复核结果优先级高于 AI 评分，并用于反向优化评分 Rubric。

| case_id | scenario | task_type | provider | model_id | AI评分 | 人工评分 | 是否同意AI评分 | 问题类型 | 人工复核意见 | 是否需要调整评分 |
|---|---|---|---|---|---:|---:|---|---|---|---|

## 问题类型选项

- 无
- 跑题
- 格式错误
- 事实错误
- 幻觉
- 不可执行
- 安全风险
- 过度承诺
- API 调用失败
- 评分争议

## 人工抽检建议

优先抽检：

1. 高分样本
2. 低分样本
3. 争议样本
4. 安全相关样本
5. 关键产品场景样本

当人工评分与 AI 评分不一致时，应以人工复核为准，并回看评分 Rubric 是否需要调整。
