# 面向 AI 产品选型的中文大模型评测报告

> 注：本报告模板用于承接 n8n 实际运行结果。当前仓库不编造模型分数，完整结果需要在接入 API 并运行 workflow 后填写。

## 1. 项目背景

AI 产品经理在模型选型时不能只看公开排行榜，需要判断不同模型在具体业务场景中的适配度、稳定性、成本、速度和安全风险。

## 2. 测评目标

本项目不判断哪个模型绝对最强，而是判断不同模型在不同产品场景下的适配度。

## 3. 测评对象

- DeepSeek
- Qwen
- Kimi / Moonshot
- 豆包 Doubao / 火山方舟
- 智谱 GLM
- 百度文心 / 千帆 Qianfan

## 4. 测评方法

- 场景化任务集
- 程序规则校验
- LLM-as-Judge 辅助评分
- 人工抽检
- 速度、失败率、成本统计

## 5. 场景任务设计

- AI 求职助手：岗位推荐、技能差距、简历优化、面试准备、职业路径、新手计划。
- AI 文档助手：总结、抽取、重点归纳、会议纪要、风险识别、引用核验。
- AI 客服助手：意图识别、问题澄清、情绪安抚、拒答边界、售后处理、转人工。
- AI 产品经理助手：痛点拆解、MVP、PRD、用户故事、竞品分析、指标体系。
- 结构化信息处理：JSON、表格、字段抽取、SOP、标签分类、Rubric 生成。
- 可靠性与安全：幻觉风险、隐私保护、过度承诺、不确定性、纠错、安全拒答。

## 10. 人工复核方案

- 抽检比例：20%
- 抽检对象：高分、低分、争议、安全相关、关键场景样本
- 冲突处理：人工复核优先，并回看 Rubric

## 11. 项目局限

- 样本量有限。
- LLM-as-Judge 可能存在偏差。
- 成本估算需要接入真实价格表。
- 不同模型 API 参数无法完全一致。
- 仍需结合真实用户反馈。
