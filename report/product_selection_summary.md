# 产品选型建议摘要

## 1. 如何阅读模型评测结果

评测结果应结合总分、分场景表现、API 失败率、响应速度、高风险占比和人工复核意见一起阅读。单一指标不能代表模型是否适合落地。

## 2. 为什么不能只看总分

总分可能掩盖模型在关键场景的短板。比如某模型总体分数高，但在客服拒答或隐私保护场景不稳定，就不适合作为客服产品的默认模型。

## 3. 产品经理应该重点关注

- 任务成功率
- 结构化稳定性
- 事实可靠性
- 用户可用性
- 安全合规
- 响应速度
- API 失败率
- 成本

## 5. 总结

本项目的最终目标不是生成排行榜，而是为具体 AI 产品 MVP 提供模型选型依据。产品经理应结合场景目标、质量风险、成本速度和人工复核结果做决策。
